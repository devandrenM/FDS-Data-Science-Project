# FDS-Data-Science-Project
A Fundamentals of Data Science project involving data analysis, visualization, preprocessing, and insights using Python

# FDS Data Science Project

## Title
Analysis of Data Science Job Posting Trends

## Objective
To analyze the trend of Data Science job postings over different years using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
The dataset contains yearly Data Science job posting information.

## Methodology
1. Create/import the dataset.
2. Store the data using Pandas.
3. Perform basic data analysis.
4. Visualize the trend using Matplotlib.
5. Interpret the results.

## Files
- `fds_project.py` – Python source code
- `dataset.csv` – Dataset used for analysis
- `output.png` – Visualization/output

## Result
The analysis shows the trend in Data Science job postings over the selected years.
